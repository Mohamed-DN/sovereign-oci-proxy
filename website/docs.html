NeroNet Technical Documentation

Welcome to the official technical documentation for NeroNet (DARKNERO.COM / DarkNero Mesh). NeroNet is a next-generation decentralized peer-to-peer mesh networking platform and sovereign proxy routing system engineered for zero-trust enterprise security, censorship evasion, line-rate eBPF acceleration, and multi-cloud Kubernetes deployment.

1. Quickstart Guide

Install the NeroNet CLI and join the mesh with a single command:

# Install NeroNet CLI daemon (macOS / Linux) curl -fsSL https://get.darknero.com | bash # Initialize control plane sovereign-control-plane --config configs/mesh-cluster.yaml & # Join edge node as exit bridge sovereign-node --join-token <YOUR_TOKEN> --role EXIT_BRIDGE --country US

2. Architecture & Networking Principles

NeroNet operates entirely on a decentralized zero-trust model. Nodes communicate directly peer-to-peer via authenticated WireGuard/SVRN binary frames over UDP, falling back to port-443 camouflaged DERP relays only when symmetric NAT conditions prevent direct traversal.

Key Subsystems:

  • DirectFrame SVRN Protocol: 24-byte header binary wire format with cryptographic AEAD tag, monotonic sequence counter, and anti-replay sliding window.
  • eBPF / XDP Fast-Path: Line-rate packet classification in the Linux kernel driver path (XDP_DRV), redirecting active peer flows with zero userspace context switching.
  • Adaptive ICE & Disco-v4 NAT Traversal: Multi-candidate endpoint discovery querying Dual-STUN servers concurrently, sequential delta port prediction, and 256-port birthday spray.
  • Local LAN Beaconing: Zero-configuration multicast (239.255.42.99:51830) and broadcast discovery for 0-hop local high-speed routing.
  • Layered 3-Hop Onion Obfuscation: Encapsulates payloads across 3 hops (Entry Relay $\rightarrow$ Intermediate Hop $\rightarrow$ Residential Exit Bridge) with fixed 1420-byte cell padding and timing jitter injection.

4. Kubernetes & Multi-Cloud Deployment

NeroNet includes production-ready Helm charts and Kustomize overlays designed for multi-cloud deployments across OCI, AWS, GCP, DigitalOcean, Hetzner, and Vultr.

# Install via Helm with high availability helm repo add neronet https://charts.darknero.com helm install neronet-cluster charts/sovereign-mesh \ --namespace sovereign-system \ --create-namespace \ --set controlPlane.replicas=3 \ --set derpRelay.service.type=LoadBalancer \ --set edgeBridge.tolerations[0].operator=Exists

5. Security Invariants & Compliance

  1. Zero Plaintext Egress: No unencrypted payload ever traverses host interfaces.
  2. Anti-Censorship by Default: Jurisdictions under strict censorship (Russia, Egypt, China, India) are unconditionally allowed unless explicitly restricted by administrator policy.
  3. Strict Bogon Isolation: RFC 1918 private subnets and CGNAT ranges are isolated from external exit sockets.
  4. Deterministic Cryptographic Verification: All handshakes, cell decapsulations, and anti-replay counters are enforced by authenticated AEAD cipher suites.
